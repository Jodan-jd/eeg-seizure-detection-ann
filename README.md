# 🧠 EEG Signal Classification for Seizure Detection

## 📌 Overview

This project focuses on classifying EEG signals to detect epileptic seizures using signal processing techniques and artificial neural networks.

Electroencephalogram (EEG) signals contain critical information about brain activity. Accurate classification of these signals can assist in early diagnosis and monitoring of neurological disorders such as epilepsy.



## 🎯 Objective

To develop a system that:

* Processes EEG signals
* Extracts meaningful features
* Classifies signals into seizure and non-seizure categories



## 🧠 Methodology

### 🔍 Signal Processing

* Applied **Wavelet Transform** for feature extraction
* Captured both time and frequency domain characteristics



### 🤖 Classification

* Used **Artificial Neural Network (ANN)**
* Trained using:

  * Conjugate Gradient optimization



## 📊 Dataset

* Bonn EEG Dataset
* Total Signals: 500
* Categories:

  * Normal
  * Inter-ictal
  * Ictal (seizure)

## 🧠 Key Insights

* EEG signals require both time and frequency domain analysis
* Wavelet transforms are effective for non-stationary signals
* Neural networks can successfully classify seizure patterns



## ⚠️ Limitations

* Limited dataset size
* Requires further validation for clinical deployment
* Model performance depends on feature selection
